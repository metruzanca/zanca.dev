## About the talk

*The Farmer Was Replaced* is a programming game: you automate a farm by writing Python in the game's built-in editor, and the game runs it. **Lucy was Replaced** is a mod that throws the Python out and lets you write the same farm in [Gleam](https://gleam.run) instead.

Gleam is a small, statically typed, functional language so making it work is more than a syntax swap. Gleam requires a filesystem project, it has to be compiled and then we need to somehow run that code inside of a Unity game.
